Raylib Game - Portable Version

To run this game, simply double-click: main.exe

System Requirements:
- Windows 7 or later (32-bit or 64-bit)
- No additional software installation needed

All required files are included in this folder.
Do NOT delete the DLL files - they are required for the game to run.

Files included:
- main.exe                   = Game executable
- libraylib.dll              = Raylib graphics library
- glfw3.dll                  = Window management library
- libgcc_s_seh-1.dll         = MinGW runtime
- libstdc++-6.dll            = C++ standard library
- Graphics/                  = Game graphics assets
- resourse/                  = Game resources
